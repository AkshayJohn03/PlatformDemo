07 · the planted failure

The release gate

golden dataset platformdemo-golden-1 — 8 items, references quoted from the corpus
exam 1 baseline v1 (healthy) vs candidate v1 — mean 3.5312 → verdict no_change exit 0
exam 2 baseline v1 vs candidate v2 (degraded: every other word dropped) — mean 2.8519 · −19.2% → verdict regressed exit 1
the gate needs BOTH a statistically significant drop (paired bootstrap CI) and a large effect size (Cliff's delta) — it cannot be tripped by luck
A degraded model can never silently ship.
golden dataset A fixed, versioned exam — questions with reference answers — that every snapshot must sit.
regression gate Compares baseline vs candidate snapshots and decides: ship it, or block the release.
exit code 0 means pass, 1 means fail — a CI pipeline acts on that number automatically.

An architecture claim you can rerun on every push is a different kind of claim.

mock transport Mocks sit only at the transport boundary; everything above — limits, caching, metering, classification, the gate — runs for real.
